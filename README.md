# Messina Home — Web Sitesi

Bursa İnegöl'deki Messina Home koltuk mağazası ve üretim atölyesi için hazırlanmış statik web sitesi.

## Dosya Yapısı

```
ilter-dukkan/
├─ index.html        → Ana Sayfa (Hero, 5 Model Karuseli, Değerler & İletişim)
├─ urunler.html      → Koltuk Modelleri (Yıldız, Nirvana, Golf, Versace, Viyana)
├─ hakkimizda.html   → Hakkımızda
├─ iletisim.html     → İletişim (WhatsApp Formu + Harita + Çalışma Saatleri)
├─ css/style.css     → Tüm site stili (Lüks fildişi/vizon zemin + şampanya altın vurgular)
├─ js/main.js        → Çok dilli sistem (TR/EN), canlı model araması, galeri, WhatsApp yönlendirmesi
├─ images/models/    → PDF kataloğundan çıkarılmış gerçek ürün fotoğrafları ve teknik ölçü şemaları
└─ videos/           → Tanıtım videoları
```
